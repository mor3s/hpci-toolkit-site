title: First setup
description: Name a plant, attach a device, add a sensor, and see live data — the core loop, no code.
---

With the server running and a board flashed, this is the loop that sets everything up. No code is involved.

1. **Enter your name** to sign in. There is no password — this is a workshop tool.
2. You land on **Plants**. **Name a plant** (for example, "Basil"). This is the first act: naming the thing you are caring for.
3. **Tap the plant** to open its page. To sense it you need a device, so tap **Register a device** (or open *Devices & hardware*), subscribe to your board by the device id you set when flashing, then return to the plant and **attach** the device to it.
4. On the device, open **Setup** and add a sensor from the dropdown. The app allocates a pin and shows you how to wire it. **Wire it as instructed.**
5. Within seconds the board reconfigures itself and begins sending readings. Back on the **plant's page**, the section **What this plant senses** shows a live graph, sourced from the devices attached to the plant.

That is the core loop: name a plant, attach a device, add a sensor, and see the data gathered on the plant.
